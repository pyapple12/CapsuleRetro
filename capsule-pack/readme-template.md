# {{GAME_NAME}} — 使用说明

欢迎使用 **{{GAME_NAME}}**！这是一个免安装的经典 DOS 游戏包装版：双击即玩，无需安装模拟器或任何运行库。

## 文件构成

本游戏共三个文件，请放在**同一个文件夹**里：

| 文件               | 作用                                 | 可以改名 / 删除吗     |
| ------------------ | ------------------------------------ | --------------------- |
| {{GAME_NAME}}.exe  | 游戏本体（全部资源已内嵌）           | ✅ 可随意改名         |
| {{GAME_NAME}}.save | 你的存档与设置（首次游玩后自动生成） | ❌ 不要改名，不要删除 |
| readme.md          | 本说明文件                           | ✅ 可随意改名或删除   |

## 快速开始

1. 双击 `{{GAME_NAME}}.exe` 启动游戏
2. 首次启动会释放运行文件（几秒钟，之后不再重复）
3. 点击「启动 {{GAME_NAME}}」进入游戏；点「攻略」可随时查看攻略
4. 游戏内正常存档后，点「停止游戏」或直接退出即可——存档自动保存到 `.save` 文件

## 存档说明

- 所有进度都存在 `{{GAME_NAME}}.save` 里：换电脑时把它和 exe 一起拷走，存档跟着走
- exe 与 `.save` 必须在同一文件夹，否则会找不到存档
- 如果 `.save` 意外损坏，游戏会自动用全新空档继续（损坏的旧档备份为 `{{GAME_NAME}}.save.corrupt`，游戏本体不受影响）

## 常见问题

**首次运行弹出「Windows 已保护你的电脑」（SmartScreen）？**
这是未签名程序的正常提示：点「更多信息」→「仍要运行」即可。

**杀毒软件报毒？**
本程序为绿色单文件、无安装行为、不写注册表；如被误报，请添加信任。

**游戏运行异常，想重置？**
删除资源管理器地址栏中的这个文件夹后重新启动游戏（存档不受影响）：

```
%LOCALAPPDATA%\CapsuleRetro\{{GAME_DIR}}
```

运行文件会自动重新释放。
