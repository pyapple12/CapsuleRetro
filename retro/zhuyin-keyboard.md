# 注音输入对照表（XEEN 汉化版用）

> 用途：XEEN 台湾汉化版（CHINFONT/EXTBIG5）游戏内命名/输入使用注音（ㄅㄆㄇㄈ）系统。
> 本表为**标准排列**（倚天系 DOS 中文系统默认布局）的 键盘键 ↔ 注音 ↔ 拼音 三列对照，
> 供在游戏内打字时查阅。若游戏内个别键对不上，以屏幕实际显示的注音符号为准回改本表。

| 键盘 | 注音 | 拼音 | 键盘 | 注音 | 拼音 | 键盘 | 注音 | 拼音 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| `1`  | ㄅ   | b    | `q`  | ㄆ   | p    | `a`  | ㄇ   | m    |
| `2`  | ㄉ   | d    | `w`  | ㄊ   | t    | `s`  | ㄋ   | n    |
| `e`  | ㄍ   | g    | `d`  | ㄎ   | k    | `c`  | ㄏ   | h    |
| `r`  | ㄐ   | j    | `f`  | ㄑ   | q    | `v`  | ㄒ   | x    |
| `5`  | ㄓ   | zh   | `t`  | ㄔ   | ch   | `g`  | ㄕ   | sh   |
| `b`  | ㄖ   | r    | `y`  | ㄗ   | z    | `h`  | ㄘ   | c    |
| `n`  | ㄙ   | s    |      |      |      |      |      |      |

> 记忆点：ㄐㄑㄒ（j/q/x）对应 `r/f/v`；ㄓㄔㄕ（zh/ch/sh）对应 `5/t/g`。

## 二、介音（ㄧㄨㄩ）

| 键盘 | 注音 | 拼音 | 说明                    |
| ---- | ---- | ---- | ----------------------- |
| `u`  | ㄧ   | i    | 如"默"无介音，此行独用  |
| `j`  | ㄨ   | u    | ㄘㄨㄣ（存）里的 ㄨ = j |
| `m`  | ㄩ   | ü/v  | 拼音 ü 在注音是独立符号 |

| 键盘 | 注音 | 拼音 | 键盘 | 注音 | 拼音 | 键盘 | 注音 | 拼音 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| `8`  | ㄚ   | a    | `i`  | ㄛ   | o    | `k`  | ㄜ   | e    |
| `,`  | ㄝ   | ê    | `9`  | ㄞ   | ai   | `o`  | ㄟ   | ei   |
| `l`  | ㄠ   | ao   | `.`  | ㄡ   | ou   | `0`  | ㄢ   | an   |

## 四、声调键

| 键盘 | 声调   | 说明                    |
| ---- | ------ | ----------------------- |
| 无   | 一声   | 打完注音直接上屏/出候选 |
| `6`  | 二声 ˊ | 如"存" ㄘㄨㄣˊ          |
| `3`  | 三声 ˇ |                         |
| `4`  | 四声 ˋ | 如"默/认/档"            |
| `7`  | 轻声 ˙ |                         |

## 五、XEEN 实战备忘

- **打字顺序**：声母 → 介音 → 韵母 → 声调键 → 底部候选窗按数字键选字
- **翻页**：候选不在本页按**空格**下一页（`-` 上一页）；注意空格兼职一声与翻页，先补声调再翻页
- **中英切换**：DOS 台湾中文系统惯例 **Ctrl+空格**；游戏命名栏位有时自动进注音模式
- **Big5 只有繁体**：简体的"档/认/设"不存在，必须从候选选 檔/認/設
- **示例**（存档命名）：
  - "默認存檔"：`ai4` → `bp4` → `hjp6` → `2;3`
  - "預設存檔"（台湾说法）：`m4` → `gk4` → `hjp6` → `2;3`
- **偷懒方案**：若只求能认，命名栏大概率也收纯英文名（直接敲字母）
